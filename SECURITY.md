# Security Policy

CyberTrace projects prioritize security, privacy, and responsible disclosure.  
If you discover a vulnerability, we ask that you follow the guidelines below to ensure issues are handled quickly and safely.

## Supported Versions

Security updates are provided for the latest version of the project.  
Older versions may not receive patches unless the issue is critical.

## Reporting a Vulnerability

If you believe you’ve found a security vulnerability, please report it privately.

Contact:
**mattyhammel17@gmail.com**

Include:
- A clear description of the issue  
- Steps to reproduce  
- Potential impact  
- Any relevant logs, screenshots, or proof‑of‑concepts  

Please **do not** open a public GitHub issue for security vulnerabilities.

## Responsible Disclosure

We ask that you:
- Report vulnerabilities privately first  
- Allow maintainers reasonable time to investigate and patch  
- Avoid exploiting the issue beyond what is necessary for proof‑of‑concept  
- Avoid sharing details publicly until a fix is released  

We commit to:
- Acknowledging your report promptly  
- Investigating the issue thoroughly  
- Providing a fix or mitigation  
- Communicating transparently once resolved  

## Scope

This policy applies to:
- CyberTrace tools  
- Labs  
- Documentation sites  
- Game prototypes hosted in this repository  

It does **not** apply to:
- Third‑party dependencies  
- External services (e.g., itch.io, GitHub Pages)  

## Thank You

Your efforts help keep the CyberTrace ecosystem secure and reliable.  
We appreciate responsible researchers and contributors who help strengthen the platform.
