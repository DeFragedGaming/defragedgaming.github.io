YOUR MISSION

Tighten the baseline policy

7 VALIDATION CHECKS
  1. Remove temporary rules that allow any service through a boundary.
  2. Allow Internet → DMZ Web only for HTTPS.
  3. Allow DMZ Web → App API only for the API service.
  4. Allow Staff → Internet only for HTTPS; preserve default deny for everything else.
How evaluation works

Rules are checked from top to bottom. The first matching rule decides the action. If nothing matches, the firewall denies the traffic.

DEFENSE TAKEAWAYS

A safer perimeter starts with explicit intent

Least privilegePermit only the source, destination, and service needed for a documented business function.

Segment the DMZA public-facing service should not have broad access to internal hosts or data stores.

Validate after changesTest both expected access and traffic that should remain blocked; review rule order and logs.

This is an educational simulation. It does not configure a real firewall, send packets, or change network access.
