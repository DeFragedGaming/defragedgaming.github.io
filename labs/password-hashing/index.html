PBKDF2 + unique salt

A configurable password-based derivation function. Each record gets its own random salt and work factor.

PRACTICAL TAKEAWAYS

Production password storage

  • Prefer a modern, dedicated password-hashing function such as Argon2id; scrypt, bcrypt, or PBKDF2 may be appropriate where required.
  • Use a unique cryptographically random salt for each password and store it with the algorithm and parameters.
  • Choose and periodically review work parameters for your server capacity; this browser demo is not a deployment recommendation.
  • Never store plaintext passwords or use reversible encryption as a substitute for password hashing.
  • Use established libraries and follow current organizational and platform guidance rather than implementing storage yourself.
