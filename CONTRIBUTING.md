# Contributing to CyberTrace Projects

Thank you for your interest in contributing. This project maintains a high standard for code quality, clarity, and professionalism. The guidelines below ensure consistent contributions and a clean development workflow.

## Code of Conduct
By participating in this project, you agree to follow the Contributor Covenant Code of Conduct.

Full text:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## How to Contribute

### 1. Fork the Repository
Create your own fork and work from a feature branch.

### 2. Use Clear, Professional Commit Messages
Commit messages should:
- Describe the change clearly  
- Use present‑tense, concise language  
- Follow this format:


Examples:
- `feat(ui): add new panel layout`
- `fix(core): resolve null reference in generator`
- `docs: update installation instructions`

### 3. Follow Project Structure and Naming Conventions
Keep files organized and consistent with the existing architecture.  
Avoid introducing unnecessary folders, unused files, or inconsistent naming.

### 4. Code Quality Requirements
All contributions must:
- Be modular and maintainable  
- Avoid unnecessary complexity  
- Include comments only where needed  
- Match the existing formatting and style  
- Avoid unused variables, dead code, or console logs  

### 5. Submitting a Pull Request
When opening a PR:
- Provide a clear summary of the change  
- Include screenshots if UI‑related  
- Reference related issues if applicable  
- Ensure the branch is up to date with `main`  

PRs that do not meet the project standards may be closed or requested for revision.

## Reporting Issues
If you encounter bugs, security concerns, or unexpected behavior:
- Open an issue with a clear description  
- Include reproduction steps  
- Add logs or screenshots if relevant  

Security‑related issues should be reported privately when possible.

## Feature Requests
Feature ideas are welcome. When submitting:
- Explain the purpose  
- Describe the problem it solves  
- Provide examples or mockups if applicable  

## Thank You
Your contributions help strengthen the CyberTrace ecosystem and improve the tools, labs, and experiences built here.
